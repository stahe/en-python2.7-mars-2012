## 📌 Overview

This project offers a collection of Python scripts covering various technical fields. It is not a theoretical course, but a **collection of practical examples** designed to provide a quick introduction.

### Topics covered:

**Fundamentals** of the Python language.

* **MySQL** database management.

* TCP/IP network programming

* **Web** programming.

* **Three-tier** architectures and **interface**-based programming.

---

## 🎯 Target Audience

This document is intended for developers who already have experience with:

* Scripting languages (**Perl, PHP, VBScript**).
* Typed languages (**Java, C#**) and who wish to explore object-oriented programming in Python.

> [!IMPORTANT]
> This content is **inappropriate** for complete beginners in programming. It is not intended to teach absolute "best practices"; an experienced developer may judge that certain code could be optimized.

## 📖 How to use this collection

To get the most out of this repository, **active reading** is essential. For each script, you will find:
* Annotated source code.
* A reproduction of the console output.
* Additional explanations where necessary.
